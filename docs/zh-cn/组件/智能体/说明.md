# Agent

智能体（Agent）是 iSerf 的核心组件，负责与大模型交互、管理记忆、调用工具、处理事件。

## 核心类

| 类名 | 说明 |
|------|------|
| `Agent` | 智能体主类，管理运行循环、事件处理、状态恢复 |
| `AgentConfig` | 智能体配置，包含 LLM、工具、持久化等 |
| `AgentEvent` | 事件定义，驱动智能体行为 |
| `AgentMessage` | 消息定义，包含对话内容、工具调用等 |
| `AgentMetadata` | 元数据，包含 id、orgId、userId 等 |
| `AgentSnapshot` | 持久化快照，包含恢复所需完整状态 |

## 构造与配置

### AgentConfig

```java
@Data
public class AgentConfig {
    private AgentMetadata metadata;      // 元数据
    private String prompt;               // 系统提示词
    private ILlmProvider llm;            // LLM 实例
    private List<Tool<?>> tools;         // 工具列表
    private IAgentPersistence persistence; // 持久化实现，null 则使用 NoneAgentPersistence
    private ILedger ledger;              // 计费账本，null 则使用默认
    private Path workDir;                // 工作目录
    private ISchedule schedule;          // 定时任务调度器
}
```

### 构造方式

```java
// 方式一：通过配置类构造
var config = new AgentConfig();
config.setMetadata(AgentMetadata.builder().id("agent-1").orgId("org-1").userId("user-1").build());
config.setPrompt("你是一个助手");
config.setLlm(llmProvider);
config.setTools(tools);
var agent = new Agent(config);

// 方式二：空构造，用于纯数据构造（如反序列化）
var agent = new Agent();
```

### 自动恢复

构造时自动调用 `persistence.create(agent)`：
- 返回 `true`：新创建，无需恢复
- 返回 `false`：已存在，自动调用 `loadFromPersistence()` 恢复状态

## 事件系统

### 事件类型

| 类型 | 说明 |
|------|------|
| `MESSAGE` | 用户消息，触发 LLM 对话 |
| `REDO` | 重做事件，从指定 eventId 重做 |
| `ORGANIZE_MEMORY` | 整理记忆，触发记忆压缩 |

### 触发事件

```java
// 发送用户消息
agent.send("你好");

// 带格式的消息
agent.send("解析这段JSON", MyFormat.class);

// 重试最后一条用户消息
agent.retry();

// 从指定事件重做
agent.redoFrom(eventId);
```

### 运行循环

```java
agent.run();  // 启动事件循环

// 订阅消息流
agent.subscribe(message -> {
    System.out.println(message.getText());
});
```

## 消息结构

### AgentMessage

```java
@Data
public class AgentMessage {
    public String id;
    public String role;        // USER / ASSISTANT / SYSTEM / TOOL
    public String type;        // TEXT / IMAGE / VIDEO / AUDIO / TOOL_CALLS / THINKING / ERROR / CUSTOM
    public String text;
    public List<String> files; // 图片列表
    public String video;
    public String audio;
    public List<ToolCall> toolCalls;
    public Object formatted;   // 格式化输出对象
    public Usage usage;        // Token 使用量
    public Integer isSegment;  // 是否为流式片段
    public Integer isForgotten; // 是否已遗忘
    public String eventId;     // 关联事件ID
}
```

### 消息类型

| TYPE | 说明 |
|------|------|
| `TEXT` | 文本内容 |
| `IMAGE` | 图片 |
| `VIDEO` | 视频 |
| `AUDIO` | 音频 |
| `TOOL_CALLS` | 工具调用 |
| `THINKING` | 思考过程 |
| `ERROR` | 错误信息 |
| `CUSTOM` | 自定义内容 |
| `MIXED` | 混合消息 |

## 错误处理

智能体在事件循环中捕获异常后：

1. **回滚记忆**：根据事件类型删除相关记忆
2. **通知下游**：发送 ERROR 类型消息
3. **继续运行**：不终止事件循环（除非是 InterruptedException）

```java
// 子类可覆盖以自定义错误处理
@Override
protected Exception handleError(Exception e) {
    log.error("handleError", e);
    return e;
}
```

## 线程资源分配

智能体使用虚拟线程池处理事件：

```java
// 事件处理线程池
eventPool = Executors.newThreadPerTaskExecutor(
    Thread.ofVirtual().name("Agent-Event-", 0).factory()
);

// 消息广播线程池
broadcastPool = Executors.newThreadPerTaskExecutor(
    Thread.ofVirtual().name("Agent-Broadcast-", 0).factory()
);
```

- 事件循环在 `eventPool` 中串行执行
- 消息广播在 `broadcastPool` 中并行执行
- 使用 `PriorityBlockingQueue` 按优先级排序事件

## 性能

### 计费统计

```java
// 计算内存账单
agent.calcMemoryBillings();
```

使用 JOL（Java Object Layout）统计内存大小，记录到 Ledger。

### Token 使用量

每条 ASSISTANT 消息包含 `Usage` 信息：

```java
@Data
public static class Usage {
    public Integer total;              // 总 Token
    public Integer promptTotal;        // 输入 Token
    public Integer completionTotal;    // 输出 Token
    public Integer completionThinking; // 思考 Token
}
```

## 快照机制

智能体支持导出/恢复完整状态：

```java
// 导出快照
AgentSnapshot snapshot = agent.toSnapshot();

// 从快照恢复
agent.applySnapshot(snapshot);
```

### AgentSnapshot

```java
@Data
public class AgentSnapshot {
    public AgentMetadata metadata;     // 元数据
    public List<AgentMessage> memories; // 记忆
    public List<AgentEvent> events;     // 事件
    public List<CallCache> toolCalls;   // 工具调用缓存
    public List<Plan> plans;            // 定时任务计划
}
```

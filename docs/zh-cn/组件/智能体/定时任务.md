# 定时任务

智能体支持定时任务功能，可以按计划执行特定操作。

## 核心类

| 类名 | 说明 |
|------|------|
| `ISchedule` | 调度器接口 |
| `Schedule` | 调度器实现，基于 cron 表达式 |
| `Plan` | 任务计划定义 |

## 任务计划

```java
@Data
@Builder
@NoArgsConstructor
@AllArgsConstructor
public class Plan {
    public String id;                      // 计划 ID
    public String description;             // 计划描述
    public String cron;                    // cron 表达式（周期任务）
    public LocalDateTime time;             // 执行时间
    public String functionName;            // 函数名称
    public Map<String, Object> functionParams; // 函数参数
    public BiConsumer<Context, Map<String, Object>> function; // 执行函数
    public Context context;                // 执行上下文
}
```

## 调度器接口

```java
public interface ISchedule {
    // 添加计划
    void addPlan(Plan plan);

    // 删除计划
    void removePlan(String planId);

    // 获取所有计划
    List<Plan> getPlans();
}
```

## 使用方式

### 在 Agent 中配置

```java
var schedule = new Schedule();
schedule.start(); // 启动调度器

var config = new AgentConfig();
config.setSchedule(schedule);
var agent = new Agent(config);
```

### 程序化添加计划

```java
// 添加一次性计划
agent.addPlan(
    null,                                    // cron（null 表示一次性）
    LocalDateTime.now().plusHours(1),        // 执行时间
    "sendReminder",                          // 函数名称
    (params) -> {
        System.out.println("发送提醒");
    },
    Map.of("message", "会议即将开始")         // 参数
);

// 添加周期计划
agent.addPlan(
    "0 0 9 * * ?",                           // 每天9点执行
    null,                                    // time（由 cron 生成）
    "dailyReport",
    (params) -> {
        System.out.println("生成日报");
    },
    null
);
```

### 直接操作 Schedule

```java
var plan = Plan.builder()
        .id(UUID.randomUUID().toString())
        .description("每小时检查一次")
        .cron("0 0 * * * ?")
        .function((context, params) -> {
            // 执行逻辑
        })
        .build();

schedule.addPlan(plan);
```

## Schedule 实现

### 启动与停止

```java
var schedule = new Schedule();

// 启动调度器（每秒检查一次）
schedule.start();

// 停止调度器
schedule.stop();
```

### 执行机制

1. **检查频率**：每秒检查一次是否有计划需要执行
2. **时间匹配**：比较当前时间与计划的 `time` 字段
3. **周期更新**：cron 类型执行后自动计算下次时间
4. **虚拟线程**：使用虚拟线程池执行任务

### Cron 支持

使用 Quartz cron 表达式：

```
格式：秒 分 时 日 月 周 [年]

示例：
"0 0 9 * * ?"      - 每天9点
"0 0/5 * * * ?"    - 每5分钟
"0 0 12 ? * WED"   - 每周三中午12点
"0 15 10 ? * *"    - 每天10:15
```

## 持久化

定时任务计划会被持久化：

```java
// 添加计划后自动持久化
persistence.syncPlan(agent);

// Agent 恢复时自动加载计划
agent.applySnapshot(snapshot);
```

## 计划类型

### 一次性计划

```java
var plan = Plan.builder()
        .time(LocalDateTime.of(2024, 12, 25, 10, 0))
        .function((ctx, params) -> { /* ... */ })
        .build();
```

### 周期计划

```java
var plan = Plan.builder()
        .cron("0 0 9 * * ?")  // 每天9点
        .function((ctx, params) -> { /* ... */ })
        .build();
```

### 相对时间计划

通过工具调用添加相对时间计划：

```java
// 例如：10分钟后执行
agent.addPlan(null, LocalDateTime.now().plusMinutes(10), "task", function, params);
```

## 内置工具

iSerf 提供了内置的定时任务工具：

| 工具 | 说明 |
|------|------|
| `AddAbsolutePlan` | 添加绝对时间计划 |
| `AddPeriodicPlan` | 添加周期计划 |
| `AddRelativePlan` | 添加相对时间计划 |

这些工具可以被 LLM 调用，实现自然语言创建定时任务。

## 注意事项

1. **时间精度**：检查频率为1秒，时间精度为秒级
2. **线程安全**：计划列表使用线程安全操作
3. **持久化**：计划变更后会同步到持久化存储
4. **恢复**：Agent 启动时自动恢复之前的计划

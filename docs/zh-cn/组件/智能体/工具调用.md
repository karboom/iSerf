# 工具调用

iSerf 提供了灵活的工具调用系统，支持多种工具类型和集成方式。

## 核心类

| 类名 | 说明 |
|------|------|
| `ToolHandler` | 工具调用处理器，负责工具调用、缓存管理、自进化 |
| `Tool` | 工具定义，包含名称、类型、参数、函数 |
| `CallCache` | 工具调用缓存，用于重复调用 |
| `CallResult` | 调用结果，包含 llm/direct/error 三种类型 |
| `Context` | 调用上下文，包含 Agent 信息 |
| `Loader` | 工具加载器，从不同来源加载工具 |

## 工具类型

| 类型 | 说明 |
|------|------|
| `FUNCTION` | 本地函数，通过 `FunctionWrapper` 接口定义 |
| `IFUNCTION` | 自我进化的函数，支持运行时代码自主进化 |
| `MCP-HTTP` | HTTP 协议的 MCP 工具 |
| `MCP-CLI` | 命令行的 MCP 工具 |

## 工具定义

```java
@Data
public class Tool<T> {
    public String name;           // 工具名称
    public String description;    // 工具描述
    public String type;           // FUNCTION / IFUNCTION / MCP-HTTP / MCP-CLI
    public Class<T> paramType;    // 参数类型
    public FunctionWrapper function; // 本地函数（FUNCTION 类型）
    // ... MCP 相关配置
}
```

### FunctionWrapper 接口

```java
public interface FunctionWrapper<P, R> {
    CallResult run(Context context, P params);
}
```

## 工具加载

使用 `Loader` 类加载工具：

```java
var loader = new Loader(30); // 设置30秒超时

// 从工具文件加载
var tools = loader.fromToolFile(Path.of("tools.yaml"), null);

// 从 iFunction 目录加载
var tools = loader.fromIFunction("path/to/iFunction", "toolName", "version");

// 从 MCP CLI 加载
var tools = loader.fromMCPCli("mcp-command", args);

// 从 MCP HTTP 加载
var tools = loader.fromMCPHttp("https://api.example.com", headers);
```

## 工具调用流程

### 1. LLM 生成调用请求

LLM 返回 `toolCalls` 字段，包含要调用的工具列表：

```java
AgentMessage.ToolCall {
    id: "call_xxx",
    name: "get_weather",
    arguments: { "city": "北京" }
}
```

### 2. Agent 执行调用

```java
// ToolHandler.invoke 执行工具调用
var callResult = toolHandler.invoke(agent, calls);
```

### 3. 结果类型处理

调用结果 `CallResult` 包含三种类型：

```java
@Data
public class CallResult {
    public String llm;              // 返回给 LLM 继续处理
    public RuntimeException error;  // 错误信息，触发自进化
    public ObjectNode direct;       // 直接输出给用户
}
```

| 类型 | 处理方式 |
|------|----------|
| `direct` | 直接发送给用户，缓存调用参数 |
| `error` | 触发自进化，修复后重试 |
| `llm` | 返回给 LLM 继续对话 |

## 工具调用缓存

支持缓存工具调用参数，用于重复调用：

```java
@Data
public class CallCache {
    public String callId;        // 调用 ID
    public String toolName;      // 工具名称
    public String toolVersion;   // 工具版本
    public Map<String, Object> params; // 调用参数
}
```

### 缓存操作

```java
// 添加缓存
toolHandler.addCache(cache);

// 获取所有缓存
List<CallCache> caches = toolHandler.getCaches();

// 从缓存调用
ObjectNode result = agent.invokeToolCallCache(callId);
```

## 自我进化

iFunction 支持运行时自我进化：

### 触发条件

当工具调用返回 `error` 时触发：

```java
// 捕获工具调用错误
// 收集输入参数和错误信息
// 调用 LLM 生成修复后的代码
// 编译、加载并测试修复后的代码
// 成功则继续，失败则重试（最多 maxEvoRetry 次）
```

### 进化流程

1. 捕获错误信息
2. 收集输入参数和错误上下文
3. 调用 LLM 分析错误并修复代码
4. 编译修复后的代码
5. 加载新版本并测试
6. 成功则继续，失败则重试

### 最大重试次数

```java
var toolHandler = new ToolHandler(tools, 5); // 最多重试5次
```

## 流式工具调用合并

支持合并流式返回的工具调用片段：

```java
// 合并流式 toolCall 输出
List<AgentMessage.ToolCall> merged = toolHandler.merge(streamChunks);
```

## 错误处理

### 工具未找到

```java
if (matchedTool == null) {
    result.setLlm("Tool not found: " + call.name);
}
```

### 调用异常

```java
try {
    result = matchedTool.getFunction().run(context, params);
} catch (Exception e) {
    result.setError(e);
}
```

### 自进化重试

```java
// 错误触发 updateWithRetry
toolHandler.updateWithRetry(agent, toolCall, maxEvoRetry).subscribe();
```

## 工具更新

根据错误反馈更新工具内容：

```java
// 更新工具（已废弃）
Mono<Void> update = toolHandler.update(agent, toolCall);

// 带重试的更新
Mono<Void> update = toolHandler.updateWithRetry(agent, toolCall, maxRetry);
```

## 在 Agent 中使用

```java
// 配置工具
var config = new AgentConfig();
config.setTools(List.of(
    Tool.builder()
        .name("get_weather")
        .description("获取天气")
        .type(Tool.TYPE.FUNCTION)
        .paramType(WeatherParam.class)
        .function((context, param) -> {
            var weather = weatherService.getWeather(param.city);
            return CallResult.builder()
                .direct(JSONUtil.toJsonNode(weather))
                .build();
        })
        .build()
));

var agent = new Agent(config);
```

# 记忆管理

记忆管理器（`MemoryManager`）负责管理智能体的对话历史，包括记忆的增删查、压缩和长期记忆提取。

## 核心类

```java
@Data
@Slf4j
public class MemoryManager {
    private String systemPrompt;                    // 系统提示词
    private final List<AgentMessage> messages;      // 对话记忆列表
}
```

## 基础操作

### 添加记忆

```java
// 添加单条消息
memoryManager.add(message);

// 批量添加消息
memoryManager.addAll(messageList);
```

### 删除记忆

```java
// 删除指定 eventId 的所有消息
memoryManager.removeByEventId(eventId);

// 删除指定 eventId 及之后的所有消息（用于重做）
memoryManager.removeFromEventId(eventId);
```

### 查询

```java
// 获取消息数量
int size = memoryManager.size();

// 是否为空
boolean empty = memoryManager.isEmpty();
```

## 读取方法

| 方法 | 说明 | 使用场景 |
|------|------|----------|
| `getMessagesRaw()` | 返回实际列表引用（不含 systemPrompt） | 内部场景，如计费 |
| `getMessages()` | 返回防御性副本（不含 systemPrompt） | 外部读取，避免修改 |
| `getActiveMessages()` | 返回未遗忘的消息（过滤 THINKING） | 获取有效对话 |
| `getMessagesForLLM()` | 返回发送给 LLM 的完整消息列表 | 调用 LLM |

### 遗忘标记

消息通过 `isForgotten` 字段标记是否遗忘：
- `0` 或 `null`：未遗忘，参与对话
- `1`：已遗忘，被压缩为摘要

```java
// 获取未被遗忘的消息
List<AgentMessage> active = memoryManager.getActiveMessages();
```

## 压缩对话

当对话历史过长时，自动压缩为摘要以节省 Token。

### 触发条件

```java
// 检查 prompt token 是否超过 150k，超过则压缩
memoryManager.checkAndOrganize(agent);
```

### 压缩流程

```java
public void organizeMemory(Agent agent) {
    // 1. 构造压缩提示
    var summaryPrompt = AgentMessage.builder()
            .role(AgentMessage.ROLE.USER)
            .text("请将以上对话历史压缩为简洁的摘要，保留关键信息和上下文，用于后续对话参考。")
            .build();

    // 2. 调用 LLM 生成摘要
    var list = new ArrayList<>(messages);
    list.add(summaryPrompt);
    var result = agent.getLlmProvider().get(null, null, null).query(list, null);

    // 3. 将摘要添加到记忆
    var summaryItem = AgentMessage.builder()
            .id(UUID.randomUUID().toString())
            .role(AgentMessage.ROLE.ASSISTANT)
            .type(AgentMessage.TYPE.TEXT)
            .text(summaryText)
            .isForgotten(0)
            .build();
    messages.add(summaryItem);

    // 4. 将原消息标记为遗忘
    messages.forEach(item -> {
        if (item.getIsForgotten() == null || item.getIsForgotten() == 0) {
            item.setIsForgotten(1);
        }
    });

    // 5. 摘要自身不遗忘
    summaryItem.setIsForgotten(0);
}
```

### 手动触发

```java
// 通过事件触发压缩
agent.trigger(AgentEvent.builder()
        .type(AgentEvent.Type.ORGANIZE_MEMORY)
        .build());
```

## 长期记忆管理

### 记忆提取

在对话过程中，系统会自动提取关键信息作为长期记忆：

1. **实时提取**：每次对话后检查是否有值得记住的信息
2. **压缩保留**：压缩时保留关键上下文
3. **遗忘机制**：旧对话被标记为遗忘，但摘要保留关键信息

### 记忆结构

```
┌─────────────────────────────────────────┐
│  系统提示词 (systemPrompt)               │
├─────────────────────────────────────────┤
│  摘要 1 (isForgotten=0)                  │ ← 长期记忆
├─────────────────────────────────────────┤
│  已遗忘消息 (isForgotten=1)              │ ← 被压缩的历史
│  已遗忘消息 (isForgotten=1)              │
├─────────────────────────────────────────┤
│  摘要 2 (isForgotten=0)                  │ ← 较新的长期记忆
├─────────────────────────────────────────┤
│  活跃消息 (isForgotten=0)                │ ← 当前对话
│  活跃消息 (isForgotten=0)                │
└─────────────────────────────────────────┘
```

### 发送给 LLM

```java
// getMessagesForLLM 返回完整消息列表
List<AgentMessage> messages = memoryManager.getMessagesForLLM();
// 包含：[SYSTEM] + [未遗忘的活跃消息]
```

## 重做机制

支持从指定事件重做，删除该轮及之后的所有记忆：

```java
// 重试最后一条用户消息
agent.retry();

// 从指定事件重做
agent.redoFrom(eventId);
```

### 重做流程

1. 找到目标 USER 消息
2. 深拷贝原始消息
3. 删除该轮及之后的所有记忆
4. 全量刷盘
5. 重新触发用户消息

## 持久化

记忆管理器与持久化模块配合，确保记忆不丢失：

```java
// 增量追加（每次对话后）
persistence.addMemory(agent);

// 全量覆盖（压缩后）
persistence.syncMemory(agent);
```

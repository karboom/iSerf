# 持久化

智能体的持久化模块负责保存和恢复智能体的状态，包括记忆（Memory）和事件（Event）数据。

## 接口定义

所有持久化实现都必须实现 `IPersistence` 接口：

```java
public interface IPersistence {
    // 加载数据
    Tuple2<List<Item>, List<Event>> load(String orgId, String userId, String agentId);
    
    // 保存数据
    void save(String orgId, String userId, String agentId, List<Event> events, List<Item> memories);
}
```

## 实现类型

### NonePersistence（无持久化）

默认的持久化实现，不进行任何数据存储操作。适用于临时会话或测试场景。

```java
public class NonePersistence implements IPersistence {
    @Override
    public Tuple2<List<Item>, List<Event>> load(String orgId, String userId, String agentId) {
        return null;
    }

    @Override
    public void save(String orgId, String userId, String agentId, List<Event> events, List<Item> memories) {
        // 空实现
    }
}
```

### NfsPersistence（文件系统持久化）

使用本地文件系统或 NFS（Network File System）进行数据持久化。

#### 特性

- **存储格式**：使用 CBOR 二进制格式（比 JSON 解析快 40%，体积小 60%）
- **目录结构**：`baseDir/orgId/userId/agentId.cbor`
- **原子写入**：采用 tmp 文件 + 原子重命名机制，确保数据一致性
- **fsync 保证**：写入时调用 `channel.force(true)` 确保数据落盘

#### 数据结构

```java
@Data
@Builder
@NoArgsConstructor
@AllArgsConstructor
static public class Format {
    public List<Item> memories;    // 记忆数据
    public List<Event> events;     // 事件数据
}
```

#### 使用示例

```java
// 初始化 NFS 持久化
var persistence = new NfsPersistence("/path/to/data/dir");

// 在 Agent 中使用
var agent = new Agent("agent-id", prompt, llm, tools);
agent.persistence = persistence;
```

#### 目录结构示例

```
/data/dir/
├── org-abc123/
│   └── user-def456/
│       ├── agent-ghi789.cbor
│       └── agent-jkl012.cbor
└── org-mno345/
    └── user-pqr678/
        └── agent-stu901.cbor
```

#### 注意事项

1. **NFS 挂载优化**：由于都是小文件操作，需要做好 NFS 的挂载参数优化
2. **并发安全**：使用原子操作和临时文件机制保证并发写入安全
3. **文件格式**：当前使用 CBOR 格式，未来可扩展支持 JSON 格式

## 恢复机制

当智能体启动时，会自动调用 `recovery()` 方法从持久化存储中恢复数据：

1. 加载之前保存的记忆（Item）列表
2. 加载之前保存的事件（Event）列表
3. 将记忆添加到内存中
4. 重新触发未处理的事件（排除 RECOVERY 类型）

```java
private void handleRecovery(Event event) {
    var result = persistence.load(this.orgId, this.userId, this.id);
    
    var items = result.getT1();
    var events = result.getT2();
    
    // 恢复记忆
    items.forEach(memory::add);
    
    // 重新触发未处理的事件
    events.stream()
            .filter(e -> e.getType() != Event.Type.RECOVERY)
            .forEach(queue::offer);
}
```

## 扩展持久化实现

如需自定义持久化实现（如数据库、云存储等），只需实现 `IPersistence` 接口：

```java
public class DatabasePersistence implements IPersistence {
    @Override
    public Tuple2<List<Item>, List<Event>> load(String orgId, String userId, String agentId) {
        // 从数据库加载数据
    }

    @Override
    public void save(String orgId, String userId, String agentId, List<Event> events, List<Item> memories) {
        // 保存到数据库
    }
}

# 持久化

智能体的持久化模块负责保存和恢复智能体的状态，包括记忆（Memory）、事件（Event）、工具调用缓存（ToolCall）和定时任务计划（Plan）。

## 接口定义

所有持久化实现都必须实现 `IPersistence` 接口：

```java
public interface IPersistence {
    // 加载 Agent 完整状态
    AgentSnapshot load(AgentMetadata metadata);

    // 彻底删除 Agent 的所有持久化数据
    void remove(Agent agent);

    // region Memory
    // 全量覆盖记忆
    void syncMemory(Agent agent);
    // 增量追加记忆
    void addMemory(Agent agent);
    // endregion

    // region Event
    // 全量覆盖事件
    void syncEvent(Agent agent);
    // endregion

    // region ToolCall
    // 全量覆盖工具调用缓存
    void syncToolCall(Agent agent);
    // 增量追加工具调用缓存
    void addToolCall(Agent agent);
    // endregion

    // region Plan
    // 全量覆盖定时任务计划
    void syncPlan(Agent agent);
    // endregion

    // region Metadata
    // 全量覆盖元数据
    void syncMetadata(Agent agent);
    // endregion

    // region Search
    // 全局搜索 Agent
    List<AgentSnapshot> search(Map<String, Object> params);
    // endregion

    // region Lifecycle
    // 创建 Agent 持久化记录，返回 true=新建成功，false=已存在
    Boolean create(Agent agent);
    // endregion
}
```

## 实现类型

### NonePersistence（无持久化）

默认的持久化实现，不进行任何数据存储操作。适用于临时会话或测试场景。

```java
public class NonePersistence implements IPersistence {
    @Override
    public AgentSnapshot load(AgentMetadata metadata) {
        return AgentSnapshot.builder()
                .memories(List.of())
                .events(List.of())
                .toolCalls(List.of())
                .plans(List.of())
                .build();
    }

    @Override
    public void remove(Agent agent) { /* 空实现 */ }

    @Override
    public Boolean create(Agent agent) { return false; }

    // 其他方法均为空实现
}
```

### NfsPersistence（文件系统持久化）

使用本地文件系统或 NFS（Network File System）进行数据持久化。

#### 特性

- **存储格式**：使用 CBOR 二进制格式（比 JSON 解析快 40%，体积小 60%）
- **目录结构**：按 `baseDir/orgId/userId/agentId/` 组织
- **原子写入**：采用 tmp 文件 + 原子重命名机制，确保数据一致性
- **fsync 保证**：写入时调用 `channel.force(true)` 确保数据落盘
- **增量追加**：支持追加写入，超过阈值自动合并

#### 目录结构

```
/data/dir/
└── orgId/
    └── userId/
        └── agentId/
            ├── memory/              # 记忆目录（增量文件）
            │   ├── 000001.cbor
            │   ├── 000002.cbor
            │   └── index.txt        # 索引文件
            ├── toolCall/            # 工具调用缓存目录
            │   ├── 000001.cbor
            │   └── index.txt
            ├── event.cbor           # 事件数据
            ├── plan.cbor            # 定时任务计划
            └── metadata.cbor        # 元数据
```

#### 使用示例

```java
// 初始化 NFS 持久化
var persistence = new NfsPersistence("/path/to/data/dir");

// 在 Agent 配置中使用
var config = new AgentConfig();
config.setPersistence(persistence);
var agent = new Agent(config);
```

#### 注意事项

1. **NFS 挂载优化**：由于都是小文件操作，需要做好 NFS 的挂载参数优化
2. **并发安全**：使用原子操作和临时文件机制保证并发写入安全
3. **文件格式**：当前使用 CBOR 格式
4. **合并阈值**：文件数量超过 100 时自动触发合并

## 恢复机制

当智能体启动时，会自动从持久化存储中恢复数据：

```java
// 构造时自动恢复
public Agent(AgentConfig config) {
    // ... 初始化组件 ...

    // 自动创建或恢复
    var isNew = this.persistence.create(this);
    if (Boolean.FALSE.equals(isNew)) {
        this.loadFromPersistence();
    }
}

// 从快照恢复状态
public void applySnapshot(AgentSnapshot snapshot) {
    // 恢复元数据
    if (snapshot.getMetadata() != null) {
        this.metadata = snapshot.getMetadata();
    }

    // 恢复记忆
    if (snapshot.getMemories() != null && memoryManager != null) {
        memoryManager.addAll(snapshot.getMemories());
    }

    // 恢复工具调用缓存
    if (snapshot.getToolCalls() != null && toolHandler != null) {
        snapshot.getToolCalls().forEach(toolHandler::addCache);
    }

    // 恢复定时任务计划
    if (snapshot.getPlans() != null && schedule != null) {
        snapshot.getPlans().forEach(schedule::addPlan);
    }
}
```

## 扩展持久化实现

如需自定义持久化实现（如数据库、云存储等），只需实现 `IPersistence` 接口：

```java
public class DatabasePersistence implements IPersistence {
    @Override
    public AgentSnapshot load(AgentMetadata metadata) {
        // 从数据库加载数据
        return AgentSnapshot.builder()
                .metadata(metadata)
                .memories(loadMemories(metadata))
                .events(loadEvents(metadata))
                .toolCalls(loadToolCalls(metadata))
                .plans(loadPlans(metadata))
                .build();
    }

    @Override
    public void syncMemory(Agent agent) {
        // 全量覆盖记忆
    }

    @Override
    public void addMemory(Agent agent) {
        // 增量追加记忆
    }

    // 实现其他方法...
}
```

## 方法说明

| 方法 | 说明 | 使用场景 |
|------|------|----------|
| `load` | 加载完整状态 | Agent 启动恢复 |
| `create` | 创建持久化记录 | Agent 首次构造 |
| `remove` | 删除所有数据 | Agent 销毁 |
| `syncMemory` | 全量覆盖记忆 | 记忆压缩后 |
| `addMemory` | 增量追加记忆 | 每次对话后 |
| `syncEvent` | 全量覆盖事件 | 事件处理后 |
| `syncToolCall` | 全量覆盖工具缓存 | 缓存清理后 |
| `addToolCall` | 增量追加工具缓存 | 工具调用后 |
| `syncPlan` | 全量覆盖计划 | 计划变更后 |
| `syncMetadata` | 全量覆盖元数据 | 元数据变更后 |
| `search` | 搜索 Agent | 管理界面 |

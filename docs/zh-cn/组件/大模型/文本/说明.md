# 文本大模型

BaseLLM 是文本大模型的抽象基类，提供了与文本大模型交互的核心接口，支持流式对话、单次查询和批量处理三种使用模式。

## 核心功能

### send

用于持续交流，支持流式输出。

```java
abstract public Flux<OutputBO> send(
    List<Item> messages,    // 消息列表
    Class<?> outputFormat,  // 输出格式类型
    List<Tool> tools        // 可用工具列表
)
```

**返回类型**: `Flux<OutputBO>` - 响应式流，流式输出结果

**适用场景**: 需要实时获取大模型输出的场景，如对话交互

### query

用于工具查询，获取单次查询结果。

```java
abstract public OutputBO query(
    List<Item> messages,    // 消息列表
    Class<?> outputFormat   // 输出格式类型
)
```

**返回类型**: `OutputBO` - 查询结果对象

**适用场景**: 单次查询，不需要流式输出的场景

### batch

批量工具查询，提交批量任务。

```java
abstract public String batch(
    List<List<Item>> messageBatch,  // 批量消息列表
    Class<?> outputFormat           // 输出格式类型
)
```

**返回类型**: `String` - 批量任务ID

**适用场景**: 需要同时处理多个查询请求的场景

### batchTaskInfo

查看批量任务状态。

```java
abstract public TaskStatusBO batchTaskInfo(
    String taskId  // 批量任务ID
)
```

**返回类型**: `TaskStatusBO` - 任务状态对象

### taskResult

查看批量任务结果。

```java
abstract public List<OutputBO> taskResult(
    TaskStatusBO task  // 任务状态对象
)
```

**返回类型**: `List<OutputBO>` - 批量任务结果列表

## 字段说明

### OutputBO

输出结果对象，包含以下字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 响应ID |
| type | String | 响应类型 |
| choices | List<Choice> | 选择列表 |
| usage | Usage | 使用情况统计 |
| isDelta | Boolean | 是否为增量内容 |
| error | String | 错误信息 |

#### Choice

选择对象，包含：

| 字段 | 类型 | 说明 |
|------|------|------|
| text | String | 文本输出 |
| thinking | String | 思考内容 |
| toolCall | List<ToolCall> | 工具调用 |
| finishReason | String | 终止原因 |

#### Usage

使用统计，包含：

| 字段 | 类型 | 说明 |
|------|------|------|
| promptTokens | Integer | 提示词Token数 |
| completionTokens | Integer | 完成Token数 |
| thinkingTokens | Integer | 思考Token数 |
| totalTokens | Integer | 总Token数 |

### TaskStatusBO

任务状态对象，用于查询批量任务的状态信息。

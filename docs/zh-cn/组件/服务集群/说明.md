# 集群说明
提供一个支持弹性伸缩的集群服务，每个节点即提供服务，也充当路由。外层通过负载均衡来统一入口。不同节点之间通过消息总线实现数据转发和订阅，通过元数据中心维护集群运行状态。

## 架构说明
等效节点的好处是可以利用现成的负载均衡器，客户端只需要连接一个地址，对集群内部的伸缩无感。
采用消息总线进行通信解耦，有效降低大规模节点通信资源消耗，并且提供通信的可靠性。

依据Agent驻留内存的特点，类比现实世界：

扩容=新盖办公楼，新的客户引导至新的办公区

节点=办公区，客户来了，相关的智能体都来这里办公

消息总线=网线线，类似于远程办公支持

# 弹性伸缩
## 扩容流程
1. 新增服务器节点
2. 新用户和负载均衡连接
3. 负载均衡根据规则分配 websocket 连接到新的节点
4. 新用户在新节点就地创建 Agent 或者唤醒 Agent
5. 正常工作

## 缩容流程
1. 服务器节点销毁
2. 用户重新连接负载均衡
3. 负载均衡根据规则分配 websocket 连接到现有节点
4. 用户在现有节点唤醒 Agent
5. 正常工作

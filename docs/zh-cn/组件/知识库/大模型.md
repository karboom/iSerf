# 大模型检索

基于 Agentic 模式的智能文档检索组件，利用大语言模型理解文档结构和用户查询意图，实现精准的文档内容检索。

## 功能特性

- **智能索引构建**: 自动分析 Markdown 文档结构，生成层次化的文档索引
- **语义检索**: 通过大语言模型理解用户查询意图，精准匹配相关节点
- **Redis 持久化**: 使用 Redis 存储文档索引结构，支持高效查询
- **灵活配置**: 支持自定义索引构建选项（节点摘要、精简策略等）

## 快速开始

### 1. 创建 Agentic 实例

```java
var agentic = new Agentic();
```

Agentic 类会自动初始化以下组件：
- `RedisClient`: 连接本地 Redis 服务
- `RedisStructStore`: 基于 Redis 的结构化存储
- `MarkdownTreeBuilder`: 文档索引构建器，使用 qwen-plus 模型

### 2. 构建文档索引

```java
var taskId = agentic.buildIndex(Paths.get("path/to/your/document.md"));
```

`buildIndex` 方法会：
1. 读取指定的 Markdown 文件
2. 调用大语言模型分析文档结构
3. 生成层次化的索引结构
4. 将索引存储到 Redis
5. 返回任务 ID 用于后续检索

**索引构建选项**（默认配置）：
- `ifThinning(false)`: 不禁用精简功能
- `minTokenThreshold(100)`: 最小 Token 阈值
- `ifAddNodeSummary(true)`: 添加节点摘要
- `ifAddNodeText(false)`: 不添加节点原文
- `summaryTokenThreshold(200)`: 摘要 Token 阈值
- `ifAddNodeId(true)`: 添加节点 ID
- `ifAddDocDescription(true)`: 添加文档描述

### 3. 执行文档检索

```java
var query = "2023 年的收入是多少？";
var result = agentic.search(query, taskId);
System.out.println(result);
```

`search` 方法会：
1. 根据 taskId 加载文档索引
2. 调用大语言模型分析查询与索引的匹配关系
3. 返回包含 `thinking` 和 `nodeIds` 的 `IndexHit` 结果
4. 根据节点 ID 收集匹配的文档内容
5. 返回检索到的文档片段

## 核心类说明

### Agentic

主检索类，提供索引构建和检索功能。

**成员变量**：
- `dir`: 工作目录
- `redisClient`: Redis 客户端
- `structStore`: 结构化存储接口
- `builder`: Markdown 树构建器

**主要方法**：

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `buildIndex(Path filePath)` | `filePath`: Markdown 文件路径 | `String`: 任务 ID | 构建文档索引 |
| `search(String query, String taskId)` | `query`: 查询语句<br>`taskId`: 索引任务 ID | `String`: 检索结果 | 执行文档检索 |

### IndexHit

检索结果数据结构。

```java
@Data
@Builder
@NoArgsConstructor
@AllArgsConstructor
public static class IndexHit {
    public String thinking;        // 模型思考过程
    public List<String> nodeIds;   // 匹配的节点 ID 列表
}
```

## 使用示例

完整使用流程：

```java
import me.karboom.java.iSerf.rag.scene.Agentic;
import java.nio.file.Paths;

public class AgenticDemo {
    public static void main(String[] args) {
        // 创建实例
        var agentic = new Agentic();
        
        // 构建索引
        var taskId = agentic.buildIndex(Paths.get("docs/2023-annual-report.md"));
        System.out.println("索引构建完成，任务 ID: " + taskId);
        
        // 执行检索
        var query = "What is the company's revenue in 2023?";
        var result = agentic.search(query, taskId);
        System.out.println("检索结果：");
        System.out.println(result);
    }
}
```

## 环境要求

### 依赖服务

1. **Redis**: 用于存储文档索引结构
   - 默认连接：`redis://localhost`
   - 可通过构造函数自定义配置

2. **大语言模型 API**: 用于文档分析和检索
   - 默认模型：`qwen-plus`
   - 需要设置环境变量：
     - `OPENAI_API_KEY`: API 密钥
     - `OPENAI_BASE_URL`: API 基础 URL

### 环境变量配置

```bash
export OPENAI_API_KEY="your-api-key"
export OPENAI_BASE_URL="https://api.example.com"
```

## 注意事项

- 文档格式必须为 Markdown
- 索引构建是异步过程，可通过 `taskId` 查询任务状态
- 检索结果依赖于大语言模型的理解能力，建议使用 temperature=0.0 以获得稳定结果
- 目前支持单文档检索，跨文档搜索和递归搜索功能待实现

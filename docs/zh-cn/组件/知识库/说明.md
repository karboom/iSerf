# 知识库

根据不同数据源的特性，提供不同的数据结构设计和检索方式

## 三种知识库类型对比

| 特性 | 大模型检索 (Agentic) | 结构化存储 (StructStore) | 向量检索 (Vector) |
|------|---------------------|------------------------|------------------|
| **核心原理** | 利用大语言模型理解文档结构和查询意图 | Schema 驱动的结构化数据查询（类似 GraphQL） | 向量相似度搜索 + 条件过滤 |
| **存储方式** | Redis Hash 存储层次化树结构 | 结构化 JSON 文档，支持字段级查询 | 支持向量索引的数据库 |
| **检索方式** | LLM 语义匹配节点 ID | 结构化查询语言，灵活选择返回字段 | 混合搜索（向量 ANN + 条件过滤） |
| **数据结构** | Markdown 树形索引（TreeNode 层次结构） | 预定义 Schema 的层次化数据 | 带向量字段的扁平记录 |
| **适用场景** | 长文档/报告/手册的精准片段检索 | 复杂关系数据查询、跨实体关联 | 用户记忆/语义搜索/推荐匹配 |
| **查询特点** | 自然语言提问，返回思考过程 + 节点 ID | 声明式查询，按需获取字段 | 语义相似 + 元数据过滤 |
| **典型用例** | "2023 年的收入是多少？" | 查询用户及其关联的订单和评论 | "找出与用户 A 相关的记忆" |

## 1. 大模型检索 (Agentic)

### 核心特性
- **智能索引构建**: 自动分析 Markdown 文档结构，生成层次化索引
- **语义检索**: 通过大语言模型理解查询意图，精准匹配相关节点
- **可解释性**: 返回模型的思考过程 (`thinking`) 和匹配的节点 ID 列表

### 数据结构
```
Document Tree
├── TreeNode (nodeId: "0001", title: "第一章", level: 1)
│   ├── TreeNode (nodeId: "0002", title: "1.1 节", level: 2)
│   └── TreeNode (nodeId: "0003", title: "1.2 节", level: 2)
└── TreeNode (nodeId: "0004", title: "第二章", level: 1)
```

### 使用场景
- **技术文档检索**: API 文档、用户手册、故障排查指南
- **财报/报告分析**: 从长篇报告中提取特定数据（收入、利润等）
- **合同/法律文档**: 快速定位特定条款内容
- **知识库问答**: 基于产品文档的智能客服

### 快速示例
```java
var agentic = new Agentic();
var taskId = agentic.buildIndex(Paths.get("docs/manual.md"));
var result = agentic.search("如何重置密码？", taskId);
```

## 2. 结构化存储 (StructStore)

### 核心特性
- **Schema 驱动**: 类似 GraphQL 的类型系统，预定义数据结构
- **层次化查询**: 支持嵌套对象的灵活查询和字段选择
- **声明式 API**: 按需指定返回字段，避免过度获取数据

### 数据结构
```json
{
  "query": {
    "user": {
      "id": "123",
      "name": true,
      "orders": {
        "orderId": true,
        "amount": true,
        "items": {
          "name": true,
          "quantity": true
        }
      }
    }
  }
}
```

### 使用场景
- **复杂关系数据**: 用户 - 订单 - 商品等多层关联查询
- **API 数据聚合**: 从多个数据源聚合数据并统一返回
- **动态表单/报表**: 根据前端需求动态调整返回字段
- **知识图谱查询**: 实体及其关联关系的层次化检索

### 快速示例
```java
// 结构化查询示例（类似 GraphQL）
var query = """
{
  user(id: "123") {
    name
    email
    orders {
      id
      total
      items {
        name
        price
      }
    }
  }
}
""";
var result = structStore.query(query);
```

## 3. 向量检索 (Vector)

### 核心特性
- **混合搜索**: 支持向量相似度 (ANN) + 条件过滤的组合查询
- **语义理解**: 基于 Embedding 向量的语义匹配，不依赖关键词
- **动态记忆**: 支持记忆的提取、更新和检索

### 数据结构
```json
{
  "id": "20260305001",
  "userId": "user123",
  "content": "用户喜欢 Python 编程",
  "category": "技术偏好",
  "tags": ["编程", "Python"],
  "vector": [0.123, -0.456, ...]
}
```

### 混合查询语法
```java
Map<String, Object> query = Map.of(
    "userId", "user123",           // 精确过滤
    "content|ann", vectorData      // 向量相似搜索
);
var results = vectorStore.mixedSearch(query);
```

### 使用场景
- **用户记忆系统**: 对话历史中的关键信息提取和检索
- **语义搜索**: 不依赖关键词的模糊匹配
- **推荐系统**: 基于内容相似度的物品推荐
- **知识图谱**: 概念之间的关联检索

### 快速示例
```java
var memory = new Memory(llm, embedding, vectorStore);
memory.update("user123", chatMessages);
var memories = memory.match("user123", "编程相关的话题");
```

## 选型建议

| 需求场景 | 推荐类型 | 理由 |
|---------|---------|------|
| 长文档片段检索 | 大模型检索 | LLM 理解结构，精准定位 |
| 复杂关系查询 | 结构化存储 | GraphQL 式声明查询，灵活获取关联数据 |
| 语义模糊匹配 | 向量检索 | 向量相似度，理解语义 |
| 大规模数据 | 结构化存储 + 向量检索 | 组合使用，兼顾性能和语义 |
| 实时性要求高 | 结构化存储 | 内存存储，微秒级响应 |
| 需要可解释性 | 大模型检索 | 返回思考过程 |
| 知识图谱 | 结构化存储 | 层次化查询实体关系 |
